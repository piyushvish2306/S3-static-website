# Static Website Hosted on Amazon S3

This project contains a simple static website built using HTML and CSS and deployed on Amazon S3 using static website hosting.

## 🚀 Deployment
- Created an Amazon S3 bucket
- Uploaded HTML and CSS files
- Enabled static website hosting
- Configured public access permissions
- Accessed the website using the S3 website endpoint

## 🛠 Technologies Used
- HTML
- CSS
- Amazon S3 (AWS)
